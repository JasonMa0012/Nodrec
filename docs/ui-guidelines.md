# Desktop UI 规范

本规范记录用户已确认的通用且持久的桌面交互与布局要求, 不要记录单次或临时需求。

## 应用标识

应用图标使用 UI 的粉色 #f48fb1 与白色，圆角底形和圆端 N 字形。矢量源为 apps/desktop/src-tauri/icons/icon.svg；标题栏和 About 共用该资源，Windows 与 favicon 使用同源生成的 icon.ico，icon.png 用于预览。修改源后用 Tauri icon 命令生成到临时目录，再同步 icon.ico/icon.png；不提交无关平台的生成图标。

## Resize 把手

- Resize 把手保留可操作的命中区域，但可视标记只在鼠标悬停到把手附近时显示；键盘聚焦时也显示。
- 卡片与侧栏把手不得造成横向溢出。
- 相邻卡片的调宽把手分别落在各自卡片边缘，命中区和可视标记不得在卡片间隙重叠。


## 参数行

- Details/卡片等中的参数统一采用 Label 与 Field 同行的布局，Field 在各行中对齐。
- 宽度充足时 Field 默认占参数行的 50%；长内容按当前字体和内容测量后扩宽，不遮挡 Label。Label 与 Field 无法完整同行时优先上下分行，数字和 Toggle 按实际内容计算最小宽度，不把 Label 挤成逐字换行。
- 50% 字段列会挤压 Label 时，先将 Field 收缩到内容宽度；内容宽度与完整 Label 仍无法同行时才上下分行。
- 卡片详情与卡片布局编辑器也复用同行样式；参数名和控件至少 12 CSS px，Boolean Toggle 左对齐且不带外围字段框。
- Details 中同一级的 Header 与参数左边缘对齐；仅嵌套 Header 相对上一级缩进，以表达层级。不要用带边框、背景的嵌套气泡占用横向空间。
- 每个可修改参数的右侧统一使用 Undo2 还原默认值按钮；仅偏离默认值时显示，但始终预留 18px 槽位和 4px 间距，避免字段宽度跳变。
- 多选 Details 只显示所有选中对象共有且类型兼容的参数；不同值用 `Multiple values` 提示，修改应用到全部选中对象。

## 总控栏快捷方式

- 动作把手使用 Pointer Capture 处理拖动，移动超过 4px 才开始，释放时按指针位置插入，取消或栏外释放不修改。Windows 主窗口关闭 Tauri 原生拖放接管（dragDropEnabled=false），避免干扰其他 HTML5 拖放；验收使用鼠标输入，不注入 DragEvent。

- 默认打开 Overview；Blueprint 为不可关闭的固定标签，库中保留 Graphs 列表，可切换和新建图。取消独立 Control Editor，不增加底部状态栏。
- 打开 Blueprint 时，总控栏按钮前显示拖动把手，右上角显示删除按钮；左右拖动显示插入位置，Alt+方向键排序。Overview 中隐藏编辑把手。
- 录屏节点同时显示 Record、Recording status、Recording time；两个只读控件各自带拖动把手，可以拖入总控栏、与按钮混排及删除快捷方式。节点上的原始显示保留，拖动／删除不触发动作。
- 节点动作按钮也有拖动把手，可直接拖入总控栏。同一节点动作重复拖入复用已有快捷方式；快捷方式始终引用 graphId/nodeId/action，名称和图标来自节点动作。
- 删除只移除主窗口快捷方式，保留节点及已有浮动工具条入口；删除源节点时清理失效快捷方式。主窗口与各 Region toolbar 顺序独立保存，无坐标或尺寸。
- 把手及删除操作不执行节点动作，动作按钮仍可实际操作。录制时锁定快捷方式编辑。标题栏、节点和浮动工具条共享 Record、Preparing…/Cancel、Pause/Stop/时长、Resume/Stop/时长、Saving… 状态及错误。

## 蓝图节点

- 节点内不显示 Enabled 开关；Details 保留启用操作。禁用节点置灰，启用节点标题按节点类型着色。
- 节点动作与只读控件位于数据引脚上方并平铺排列；拖动把手在节点内排序或拖至总控栏，Alt+方向键可排序，顺序随节点保存。
- 数据引脚扩大可点击区域，连接时提供宽松的目标吸附；视觉标记保持紧凑，悬停不改变引脚定位。

- 无选择时 F 适配全图；选中时 F 整理完整显式数据连通分量。Shift+F 严格只整理选中节点，单选不扩展，无选择不操作。整理保留视口和选区；录制锁定时禁止修改；输入控件内、组合 Ctrl/Alt/Meta 或长按重复不触发整理。
- 只展示数据端口和媒体流，不存在事件、函数或执行引脚。媒体主节点从左向右排列。仅完整、专属的单节点参数树放在使用节点下方；多参数与参数链放左侧，按目标输入端口排序。算法与边界见 [节点自动整理](node-layout.md)。
- 连线采用圆角 Subway + Ribbon：保留 45° 斜向直线，接合处最多 8px 圆角，重叠通道平行错位。手动路径 Pin 和拖线预览使用同样样式。整理清除范围内部的手动路径，保留边界线 Pin。
- 可接线参数与节点内部输入引脚同行，未接线时内联编辑；连线后隐藏本地编辑器，断线恢复本地值。Screen 的 Region 和 Write 的 Path 也遵循此规则。引脚及连线按 UE 默认类型颜色显示，通配值为灰色。
- Details 保留批量编辑、说明和诊断；分组可折叠。图路径显示实际蓝图名称和 Recording graph，多图由 Graphs 列表切换。
- 编码节点按 Provider/API 区分，Codec 为目录能力限定的参数，不提供可修改的 Provider 下拉框。未实现的 Codec 不列为可运行选项。
- Boolean、Byte、Integer、Integer64、Float、Double、Name、String、Text 使用对应 Make 节点。Region、Path 和媒体流有领域端口；命名值由 Define Value 单一定义，Read Value 引用。

## 字体与空间

- 所有字体最小为 12 CSS px.
- 优先用可读字体与内容自适应布局填满面板, 提高利用率，避免小字和固定空白占位。
- 蓝图库的 Parameters 和 Unexposed parameters 分区保持紧凑并支持展开／折叠；添加菜单保持独立可用。
- Blueprint 使用高密度工作区：蓝图列表作为独立侧栏，默认展开；参数导航保持紧凑，为画布和 Details 留出空间。暗色基底采用 MooaToon 文档站色板，粉色用于主要动作、选中状态和重要反馈。
