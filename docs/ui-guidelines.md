# Desktop UI 规范

本规范记录用户已确认的通用且持久的桌面交互与布局要求, 不要记录单次或临时需求。

## Resize 把手

- Resize 把手保留可操作的命中区域，但可视标记只在鼠标悬停到把手附近时显示；键盘聚焦时也显示。
- 卡片与侧栏把手不得造成横向溢出。
- 相邻卡片的调宽把手分别落在各自卡片边缘，命中区和可视标记不得在卡片间隙重叠。


## 参数行

- Details/卡片等中的参数统一采用 Label 与 Field 同行的布局，Field 在各行中对齐。
- 宽度充足时 Field 默认占参数行的 50%；长内容按当前字体和内容测量后扩宽，不遮挡 Label。Label 与 Field 无法完整同行时优先上下分行，数字和 Toggle 按实际内容计算最小宽度，不把 Label 挤成逐字换行。
- 50% 字段列会挤压 Label 时，先将 Field 收缩到内容宽度；内容宽度与完整 Label 仍无法同行时才上下分行。
- 卡片详情与卡片布局编辑器也复用同行样式；参数名和控件至少 12 CSS px，Boolean Toggle 左对齐且不带外围字段框。
- Details 中同一级的 Header 与参数左边缘对齐；仅嵌套 Header 相对上一级缩进，以表达层级。不要用带边框、背景的嵌套气泡占用横向空间。
- 每个可修改参数的右侧统一使用 Undo2 还原默认值按钮；仅偏离默认值时显示，但始终预留 18px 槽位和 4px 间距，避免字段宽度跳变。
- 多选 Details 只显示所有选中对象共有且类型兼容的参数；不同值用 `Multiple values` 提示，修改应用到全部选中对象。

## 蓝图节点

- 无选择时 F 适配全图；选中节点时 F 整理其 Event 分支，Event 和跨 Event 共享节点保持原位。选中共享数据／媒体节点时只整理共享部分，没有 Event 的图整理其连通部分。多选取对应范围的并集。
- Shift+F 严格只整理选中节点，单选不扩展，无选择不操作；Event 始终固定。整理保留视口和选区，录制锁定时禁止修改；输入控件内、组合 Ctrl／Alt／Meta 或长按重复不触发整理。
- 参数采用最多一个节点的 Helixing：仅完整、专属的单节点参数树放在使用节点下方，多参数与参数链放左侧，并按使用节点的输入引脚从上到下排列以减少交叉。左侧参数与使用节点之间至少留 120、行间留 40 个画布单位。有序扇入按引脚方向分配 Ribbon 通道，避免通道顺序再次引入交叉。范围内部连线的手动路径 Pin 清除重排，边界线的 Pin 保留。算法与限制见 [节点自动整理](node-layout.md)。
- 执行／媒体主线区域留空：整理时把左侧参数树顶部放到主节点执行／媒体引脚区域下方至少 25 个画布单位，避免参数标题或正文挡住主线。

- 连线采用圆角 Subway + Ribbon：保留 45° 斜向直线，仅在各直线段接合处加入最多 8px 的小圆角；短线段缩小圆角并保留斜线，重叠通道平行错位。手动路径 Pin 和拖线预览使用相同样式。

- 执行入口和单一执行输出放在节点标题栏左右两侧，垂直居中且不显示名称。存在多个执行输出分支时，全部移到标题下方的节点正文右侧，按端口顺序逐行排列并在引脚左侧显示完整分支名称（如 Branch 的 True／False、Select Region 的 Selected／Cancelled），行高至少 22 CSS px；不在标题栏重复显示。这是通用节点规范，不按节点类型特判。
- 执行引脚沿用方向、类型颜色与连接状态：输入和输出分别位于左右侧；已连接为实心、未连接为空心。分支名称与各自引脚同行，执行分支排在普通数据输出之前。
- 可作为节点数据输入的参数前提供右箭头导入按钮：未启用时灰显，启用时粉色高亮；启用后对应字段只读，输入连线值覆盖默认值。参数值前和行末还原按钮外侧都预留对齐宽度；Boolean Toggle 在控件列左对齐且不带外围字段框。引脚和连线按 UE 默认 GraphEditorSettings 类型颜色显示，通配值使用灰色。
- Details 分组使用清晰的 UE 风格标题栏，并可展开或折叠；节点路径显示实际蓝图名称和 `Events`。
- Boolean、Byte、Integer、Integer64、Float、Double、Name、String、Text 使用独立 Make 节点；Region、Path 和媒体流继续由对应的领域节点构造或产出。
- 每个 Register Control 节点只注册一个总控按钮。菜单项通过独立的 Register Control Menu 节点注册，并用路径（如 `Start/Start after 3s`）表示层级；Details 不提供 Children 或递归子菜单编辑器。

## 字体与空间

- 所有字体最小为 12 CSS px.
- 优先用可读字体与内容自适应布局填满面板, 提高利用率，避免小字和固定空白占位。
- 蓝图库的 Events、Functions、Parameters、Variables 分区标题保持紧凑并支持展开／折叠；添加菜单保持独立可用。
- Blueprint 使用高密度工作区：蓝图列表作为独立侧栏，默认展开；Events 导航压缩宽度，为画布和 Details 留出空间。暗色基底采用 MooaToon 文档站色板，粉色用于主要动作、选中状态和重要反馈。
