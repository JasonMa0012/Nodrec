## 迁移记录（按实现批次，早期限制可能已被后续批次替代）

- 区域选择控件已切换 select 节点动作，后端拒绝录制期间重新选区；文档控件绑定校验覆盖图、节点类型和动作，绑定控件不再需要 eventId。Control Editor 按动作类型选择录屏／选区节点，Open node 使用绑定 ID。旧注册和事件图仍未清除，真实窗口及多路录制仍待验收。

- 默认录屏控件合并为 Record 复合控件，binding 指向 recording/screen；标题栏与浮动工具条使用同一渲染器，后者通过独立命令校验工具 token、显示目标和绑定后分发节点动作。Control Editor 对录制绑定提供录屏节点选择。选择区域仍使用旧事件入口，旧图节点仍待删除；真实录制及跨窗口控制尚未验收。

- 新增主窗口 dispatch_node_action 命令及录屏节点内联控制，直接调用原生生命周期，不经过事件执行链。后端检查图／节点、启用状态、动作和会话状态；开始从录屏下游寻找写入节点。目前仍限制一个有效输出，标题栏／浮动工具条仍待切换，运行中工作区锁定也待调整；真实节点按钮录制尚未验收。

- 区域工具和所选区域由当前蓝图运行时会话持有，不写回蓝图文件；同一蓝图仅修改 UI 注册时保留选区，切换蓝图或修改选取节点配置时清理。辅助窗口调用检查会话令牌、蓝图及注册目标；关闭工具销毁辅助窗口但保留已确认选区，主窗口关闭时停止录制并退出。
- 控件与只读显示共用初始化注册顺序；状态和有效录制时长来自同一运行快照，暂停冻结、停止保留、新录制重置。

Rust 单运行时和 Tauri 命令已实现，并由 Release WebView 实际验证：

- `src-tauri/src/workflow.rs`按蓝图事件节点和执行连接串行运行；Value／Compare／Branch 根据数据连接求值。
- 控件通过初始化事件注册，运行按钮向 Rust 派发蓝图事件。状态包含 Ready、Starting、Recording、Paused、Stopping、Failed。
- 媒体事件驱动真实 `RecordingSession`；Start 等待捕获及编码／写入初始化，Stop 等待排空和文件完成后才沿 Then 继续。延迟及启动中可取消；窗口关闭在后台等待录制资源释放后销毁窗口。
- 单调时钟生成时间戳，暂停时间不计入视频时长；缺帧保留真实时间轴，不能让视频加速。快照返回实际编码器、适配器、规格、时长、编码／缺失／重复帧、最终／部分文件路径和停止耗时；UI 稳态以 500 ms 轮询更新。
- Release 端到端验证真实开始、暂停、恢复、停止、文件解码、失败反馈及延迟取消。音频、操作录制和回放未实现。
