# Runtime：会话运行

## 当前实现

Rust 单运行时和 Tauri 命令已实现，并由 Release WebView 实际验证：

- `src-tauri/src/workflow.rs`按蓝图事件节点和执行连接串行运行；Value／Compare／Branch 根据数据连接求值。
- 控件通过初始化事件注册，运行按钮向 Rust 派发蓝图事件。状态包含 Ready、Starting、Recording、Paused、Stopping、Failed。
- 媒体事件驱动真实 `RecordingSession`；Start 等待捕获及编码／写入初始化，Stop 等待排空和文件完成后才沿 Then 继续。延迟及启动中可取消；窗口关闭在后台等待录制资源释放后销毁窗口。
- 单调时钟生成时间戳，暂停时间不计入视频时长；缺帧保留真实时间轴，不能让视频加速。快照返回实际编码器、适配器、规格、时长、编码／缺失／重复帧、最终／部分文件路径和停止耗时；UI 稳态以 500 ms 轮询更新。
- Release 端到端验证真实开始、暂停、恢复、停止、文件解码、失败反馈及延迟取消。音频、操作录制和回放未实现。

## 职责与边界

协调工作流、录制／回放和结果查询；供 UI 与 MCP 使用。具体采集、存储和比较由对应模块负责。

## 一期目标

- 管理开始、停止、回放和完成过程，关联基线与回放产物。
- 协调画面、音频、输入的时间与生命周期。
- 当前限制为单蓝图单运行；运行期间锁定图编辑并阻止蓝图切换。未来再按真实需求增加并发和恢复。
