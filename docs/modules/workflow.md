# Workflow：节点工作流

## 当前实现

产品图运行模型与执行引擎未实现。UI 原型的 [graph.h](../../prototypes/imgui/graph.h) 提供固定节点样例和类型连线校验；自检覆盖无效端口、方向／类型／自身连接、输入占用、反向拖线及删除。它不是正式图格式，也没有事件／函数／子图执行能力。

## 职责与边界

表达节点连接、参数、事件、函数、子图和预设；画布交互由 Desktop 负责。

## 一期目标

- 屏幕／窗口／区域、音频、编码、写入和字符串／唯一路径节点；参数接受其他节点输出。
- 开始／每帧／结束事件、函数和子图，支持预设编辑。
- 待明确：值／流／事件调度、函数能力、类型检查、编辑历史及运行版本。

## 验收

T01、T08、T09：实际图可运行，预设可编辑，函数／子图可复用，UI／MCP 编辑一致。

## 未来规划

更多节点、调试与插件；不预设要做通用编程语言。
