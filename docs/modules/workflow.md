# Workflow：节点工作流

## 当前实现

- 新增 Select Region、Get Selected Region、Register Display；按钮／菜单／Update Control 沿用原有节点，显示目标支持主窗口与指定选区工具。默认录屏蓝图注册开始、暂停／继续、停止、状态与时间；选取工具自身不提供录制语义。详细端口及兼容规则见 [Contracts](../contracts.md)。

桌面版现有单文件 JSON 工作流、Rust 节点执行器和真实无声录屏管线：

- [workflow.rs](../../apps/desktop/src-tauri/src/workflow.rs) 提供节点目录、图校验及执行；[GraphEditor.tsx](../../apps/desktop/src/GraphEditor.tsx) 负责画布编辑与交互。
- Rust 节点目录定义事件、执行、值与媒体流端口；包含控件注册／更新、日志、可取消延迟、参数读取、常量、比较、条件分支、屏幕区域／输出路径、真实屏幕／H.264／MP4 节点，以及尚未实现的音频节点。
- On Initialize 执行 Register Control 和 Register Control Menu 节点，返回总控按钮与 Split Button 菜单；每个菜单节点只注册一个路径，例如 `Start` 与 `Start/Start after 3s`，运行时按路径组装层级。主按钮和菜单项分别绑定事件。整数 Order 控制总控栏顺序，同序号维持注册顺序；控制逻辑可更新按钮文字、图标、事件、顺序和可用状态。
- 旧版控件中的递归菜单会在加载时迁移为路径节点；新版保存不再写递归菜单数组。菜单路径最多 8 层，每个子路径必须有对应的父菜单注册。
- 没有 Order 的旧 Register Control 配置按图中注册序号推导默认值；仅在用户保存蓝图时写回文件。
- React Flow 画布从 Rust 目录载入类型化端口，可添加节点、通过可视化控件编辑参数、移动、连线、删除及复制粘贴；常规鼠标滚轮缩放、触摸板滚动平移／捏合缩放，右键拖动平移。可暴露参数由 Details 中的右箭头按钮创建同类型输入端口，启用后默认值字段只读，连线值覆盖默认值。执行入口与单一执行输出位于节点标题栏；多个执行输出在正文右侧逐行显示名称，未连接时显示空心三角。具体显示规则见 [UI 规范](../ui-guidelines.md#蓝图节点)。运行前检查节点／连线 ID、类型、方向、占用输入、执行输出、循环、事件引用和媒体管线完整性。
- Rust 单实例执行事件链；Value 节点按需求值，Branch 按 Bool 数据输出选择执行线。运行状态与界面选择不写入蓝图文件；流程节点和连接会持久化。
- 单测验证条件改变会改变路径、连线与媒体管线检查、非法引用／循环、内置文件 schema、Order 整数约束及排序和文件存储。Release WebView 端到端验证了控制注册、Order 修改后的工具栏顺序／保存、可视化参数、节点复制粘贴和录制状态流程；未实现函数／循环／子图执行；真实媒体范围见 Capture 和 Media Output。

## 职责与边界

Workflow 负责描述、校验和执行节点图；Desktop 负责编辑及展示注册控件；Runtime 管理事件调度和运行状态；媒体连线描述持续流，Start Pipeline 反向解析指定 Write 节点的依赖，开始时冻结 RecordingPlan；不逐帧解释蓝图。

## 一期目标

- 屏幕／窗口／区域、音频、编码、写入和路径节点；参数可连接节点输出。
- 开始／每帧／结束事件，函数和子图支持预设复用。
- 在定义产品执行模型前，确认值／流／事件语义、类型规则、失败行为、运行版本及编辑历史。

## 验收

T01 部分通过：屏幕录制预设可持久化，类型／循环／媒体连接校验和 Event／Branch 执行已运行验证。无声屏幕媒体节点已接入；操作录制、函数／子图执行和 UI／MCP 能力对等仍未完成。
