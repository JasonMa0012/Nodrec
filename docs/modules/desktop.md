# Desktop：预设与节点界面

## 当前实现

React + Tauri 2 桌面应用位于 [apps/desktop](../../apps/desktop)，使用 React Flow 编辑蓝图；Rust 提供节点目录、蓝图存储、运行与 Windows 录屏能力。

- 默认打开 Overview 和 Blueprint。Overview 用参数卡片配置录制；卡片与字段支持拖放、调整布局及还原默认值。各蓝图独立保存卡片布局。
- 蓝图画布支持添加、移动、连接、复制和删除节点；参数可暴露为输入端口，Details 支持多选和批量编辑。事件图和函数图都可编辑、保存；函数调用执行尚未实现。
- 画布支持路径 Pin、连线重连、右键／中键平移、滚轮缩放和自动整理。F／Shift+F 的选择范围与交互见 [UI 规范](../ui-guidelines.md)，布局算法与限制见 [节点自动整理](../node-layout.md)。触摸板平移仍有 [已知问题](../bugs/touchpad-axis-lock.md)。
- 蓝图初始化节点注册主窗口和选区工具中的按钮、菜单与状态显示。录制过程中锁定蓝图编辑和切换；浮动区域工具可选区、移动、缩放及调整参数，已确认的选区仅保留在当前蓝图会话中。
- 内置蓝图图标使用应用内提示，鼠标悬停与键盘聚焦均显示更新覆盖说明；提示通过 Portal 显示，避免侧栏滚动容器裁切。2026-10-27 独立测试副本的实际 WebView 已验证两个蓝图分别选中后的悬停显示、移开隐藏，以及键盘聚焦与 Escape 关闭。
- 蓝图可新建、复制、重命名、保存、删除和撤销删除。未保存圆点基于整个蓝图内容，因此同一蓝图的标签会一起显示；Ctrl+S 保存当前蓝图。存储位置和升级覆盖规则见 [Storage](storage.md)。
- Output folder 使用文件夹路径控件，支持直接输入和原生文件夹选择；取消选择保留原值，选择结果沿用蓝图修改、还原和保存流程。选择器仅授权主窗口。
- Settings 提供启动更新检查、代理、版本和手动更新。应用在安装更新前保存修改；安装器及签名更新细节见 [发布与更新](../releases.md)。
- 启动诊断写入终端和 `%TEMP%/nodrec-startup-<PID>.log`，记录窗口、前端资源及蓝图初始化时序；开发服务器不监听 `src-tauri/target` 构建目录。
- 内置 Screen recording 支持真实无声录屏；Operation recording 是不可运行的预览。音频、键鼠录制／回放、差异报告和 MCP 尚未实现。

界面使用英文。通用交互、参数行与字体要求集中记录在 [UI 规范](../ui-guidelines.md)；运行时和媒体接口见 [跨模块接口](../contracts.md)。

## 职责与边界

Desktop 负责导航、参数编辑、蓝图画布及运行状态展示；工作流校验和执行由 Runtime／Workflow 负责，采集及编码由对应媒体模块负责。未来 MCP 应复用产品能力，而不是依赖界面操作。

## 一期目标

- 不进入节点编辑器也能完成常用录制及未来的回放配置。
- 完善事件、函数和参数编辑，并逐步验证键盘、无障碍、多语言准备及不同窗口／DPI 的体验。
- 保留未来跨平台的桌面边界；捕获和输入仍需逐平台适配。

## 验收

已有 Release WebView 回归覆盖 Overview、蓝图、选区工具、节点整理和无声录屏；具体环境、命令及限制见 [验收文档](../testing.md)。2026-10-27 曾完成签名安装器及 0.1.1 → 0.1.2 真实更新验证，范围见 [发布与更新](../releases.md)。

函数／事件双击导航曾在 Release WebView 中各重复 8 次，标签与路径正确；该次启动日志还出现独立的 `plugin:event|listen` ACL 异常。合成输入不等同于物理鼠标、键盘或触摸板验收，混合 DPI 和 UI 内存目标也未全面验证。

## 未来规划

补齐键盘可用性、无障碍、多语言和其他平台适配，并根据实际体验与性能验证继续调整桌面方案。
