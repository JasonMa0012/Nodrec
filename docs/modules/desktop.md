## 职责与边界

提供简单预设、节点编辑器及结果查看；与 MCP 使用同等产品能力。原型用于验证 UI 接入，不充当产品运行引擎。

## 一期目标

- 两个简单预设，方便选择目标／选项、开始停止、回放及查看结果。
- 编辑预设进入节点编辑器，支持参数连线、事件、函数和子图。
- 英文 UI、底层多语言；依据原型结果再确认最终框架和外观。
