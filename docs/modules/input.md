# Input：键鼠与语义记录

## 当前实现

内置 `Operation recording` 已接好键鼠输入，打开后即可录制。自定义 Windows 录屏图可将 `Keyboard & Mouse Input → Input Events` 接到 `Write MP4 → Input Events`。节点未连接或已禁用时只写视频；连接后，录制期间会记录当前交互桌面其他前台应用的键鼠输入。多个输出共享一次设备采集。开始、暂停、继续、停止使用同一视频会话，倒计时和暂停期间不写事件。

Rust 入口为 `recording/input.rs`。Windows Raw Input 提供设备报告；时间戳是单调时钟测得的接收时间，单位为 100 ns。事件保留键盘扫描码、扩展标志、虚拟键、按下和释放，以及鼠标相对／绝对移动、按钮变化位、滚轮原值和可取得的桌面光标位置。设备 ID 仅在本会话内有效。Windows 安全桌面、系统未投递的组合键、IME 提交文本及软件注入均无完整性保证。`message_ms` 保留 Windows 消息时间（毫秒，32 位回绕），`queue_delay_ms` 记录读取时估算的队列延迟。文件可能包含用户在其他窗口输入的敏感内容。

### 查询一段录制

新录制的两份 JSONL 首行均含相同的英文 `reader_guide`，按文件后缀说明事件解码、按时间筛选和按帧读取的方法。

同目录中 `demo.input.jsonl` 是完整事件流，`demo.frames.jsonl` 是对应成品 MP4 的显示帧索引。两份文件均为 UTF-8 JSONL。v2 文件头声明列序，鼠标和键盘行使用 `[类型, ...列值]`，仅可省略文件头 `defaults` 声明的连续末尾默认值；其余对象行直接读取。帧索引每行为 `[start, end, byte_start, byte_end]`，帧号取数据行序，两个会话时间分别为 `start/end + session_shift`。文件头标明格式版本、会话、视频文件名、屏幕物理像素录制矩形和编码尺寸。

```sh
python apps/desktop/scripts/query-input.py demo.mp4
python apps/desktop/scripts/query-input.py demo.mp4 --frame 120 --raw
python apps/desktop/scripts/query-input.py demo.mp4 --time 10000000 15000000
```

查询兼容 v1 和 v2。默认按操作输出，连续的普通移动按设备及移动标志折叠为 `move`，包含起止时间、起止桌面坐标和报告数。按键、按钮、滚轮、状态快照和设备边界会结束当前移动段。第二条展开指定帧内的所有原始记录；第三条查询第 1 秒（含）到第 1.5 秒（不含）。

| 行类型 | 读取约定 |
| --- | --- |
| `key` | `seq` 为接收顺序；`device, scan, flags, vk, up` 描述单次变化。相同时间有多个报告时依次处理。重复按下仍各占一行。 |
| `mouse` | `x, y, flags` 保留 RAWMOUSE 的相对／绝对坐标及虚拟桌面标志。`button_flags` 的按下／释放可以同时出现；`wheel` 是带符号的原始增量。`cursor_px` 是处理时采样的物理桌面坐标，可能为 null。 |
| `device` | 记录设备到达／移除；移除时清除该设备的按住状态。 |
| `state` | 开始、恢复与新的一秒首次收到报告时记录快照。键元组为设备、扫描码、扩展标志、区分左右的虚拟键；按钮元组为设备和编号（左、右、中、X1、X2）。`unassigned_vk` 是启动或恢复时系统报告已按下但无法归属设备的键或按钮。 |
| `gap` | 采集异常或队列溢出；可写时将原因留在部分文件，输出状态报告失败。 |

帧号从 0 开始。`start, end` 是最终 MP4 的呈现区间，`session_start, session_end` 对应事件流时钟。用二进制模式从输入文件读取 `[byte_start, byte_end)`，得到该帧内的所有记录（含快照）；只取操作时筛选 `key` 和 `mouse`。若要知道进入该帧时有哪些键一直按住，读取帧前最近的状态快照，再按文件顺序应用快照后的状态变化。末帧以实际样本结束时间收口，视频区间以外的事件仍可按时间读取。

## 职责与边界

记录操作与定位材料；Replay 负责模拟输入，Capture 负责屏幕。

## 一期目标

- 扩展语义定位。
- 语义模式记录 UI 树和相对位置，同时考虑游戏的相对移动。
- 后续确认 UI 树采集粒度、时间和缺失语义的表示。

## 验收

T04 通过设备报告夹具检查组合键、重复、双键盘同键及同包鼠标变化；按字节索引与按时间筛选逐条比对。T05（UI 树）待实现。

2026-11-22 Windows 验证中，Release WebView 从蓝图实际生成三个成品，覆盖倒计时取消和暂停恢复。Computer Use 从创建菜单添加节点并确认输出端口；受控组合键产生可辨别的按下和释放。双输出故障测试在录制中占用其中一个事件文件的最终路径，两个 MP4 和健康输出的两份 JSONL 均正常发布，冲突文件保留原内容。暂停期间注入的标记鼠标报告未进入文件。

一次 Windows 输入压力测试发出 8,000 个带标记的移动报告，实测发送速率约 423 次/秒，全部写入。成品独立解码 1,219 帧，每帧切片与时间筛选一致。另用 32,000 个构造报告测得 Release 转换和 JSONL 写入约 43 万条/秒；该测量不含设备、驱动和 Windows 消息投递。验收机枚举到 I²C HID 指针设备。尚无实体 1–8 kHz 鼠标或双键盘同时操作的端到端测量。
