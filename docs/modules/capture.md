# Capture：图像捕获

## 当前实现

区域参数支持中心、宽高、Min/Max 的物理像素或当前屏幕百分比输入，不提供尺寸预设；Min/Max 保持对侧边固定，尺寸锁定时按独立长宽比联动。悬浮窗预留固定菜单空间，用原生窗口区域使空白位置可穿透，面板向录制框外侧展开，二级菜单横向展开。

- 区域选取工具已实现：Select Region 优先恢复当前蓝图会话中上一次有效区域（或合法的 Initial Region）；首次无有效区域、区域过小、越界、显示器不匹配或数据无效时进入桌面框选，Get Selected Region 在开始时读取最新的显示器内物理像素区域。仅八个圆形把手附近缩放，其余边框拖动；内部通过原生窗口区域挖空，允许操作下方应用。录制启动至停止完成期间锁定调整。接口见 [Contracts](../contracts.md)。

Windows 原生后端位于 `apps/desktop/src-tauri/src/recording/windows.rs`：

- Windows Graphics Capture 获取显示器纹理，D3D11 完成区域裁剪、保持比例缩放／补边和 BGRA→NV12 转换；逐帧数据不经过 WebView 或 Tauri IPC。
- 原生枚举显示器，返回监视器接口标识、名称、物理尺寸、桌面位置及 HDR 状态。枚举使用线程级 Per-Monitor V2 DPI 上下文，避免把逻辑尺寸用于物理纹理。
- 支持单显示器 Full Display／Rectangle、手填 X／Y／Width／Height 和鼠标开关。区域采用显示器内物理像素，启动时校验；录制中锁定。Source Size 的奇数尺寸向右／下补齐到偶数，不裁掉像素。
- WGC 帧池为 2 帧，硬件编码输入分配器最多 3 个 NV12 样本。编码来不及时保留最新画面并统计缺帧，静态画面复用最近纹理。
- 已在 AMD Radeon 8060S、2880×1800／225% DPI 上实录并检查区域首帧；窗口捕获、跨屏、HDR 和实时预览未实现。HDR 启动时拒绝，显示器关闭／尺寸变化会终止录制并保留部分文件。

## 职责与边界

获取目标画面、区域和图像帧；音频、编码与输入独立协作。

## 一期目标

- 补充窗口捕获；现有全屏／矩形区域、鼠标与输出规格见当前实现。
- 节点目标和参数可由其他节点提供。
- 待验证：多显示器与 DPI、窗口移动／缩放／最小化、静态画面、HDR 和目标丢失；窗口捕获的后端方案尚未确定。

## 验收

`npm run test:recording` 验证 Release 应用在非零坐标录制 897×360 区域、输出 898×360，完整解码并确认画面有变化；越界区域明确失败。副屏、混合 DPI、竖屏、显示器断开及受保护画面仍需设备实测。
