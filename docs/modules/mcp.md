# MCP：Agent 接入

## 当前实现

未实现，无 MCP 工程、工具 Schema 或连接验证。

## 职责与边界

让其他 Agent 使用 Nodrec 产品能力；不把特定客户端或 LLM 当作必需依赖。

## 一期目标

- 创建／编辑节点和工作流、控制录制／回放、查询指定帧及差异统计。
- UI 产品能力对等，包括预设、参数、函数／子图与结果操作。
- 待明确：纯编辑状态的对等范围、SDK／传输、运行宿主、并发编辑和大型结果查询；不预定 stdio 桥进程。

## 验收

T09：真实客户端完成编辑→录制→回放→查询，对照实际 UI 操作逐项检查。

## 未来规划

独立运行、远程接入、订阅与更多 Agent 集成。
