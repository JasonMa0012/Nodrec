# 节点自动整理

## BA 研究

参考本地 Blueprint Assist 4.9.2 源码：HomeDecoration 的 `Plugins/Blueprin0b23223502eaV17/Source/BlueprintAssist/`。产品页：https://www.fab.com/listings/14d7ba87-a587-406d-9369-ed75fa0a55ed 。以下为静态源码分析，未运行 UE 插件验证。

- `FBANodeActions::FormatNodes` 提交关联图整理；`FormatNodesSelectively` 用 `LimitedNodes` 限定范围，但单选时会扩展节点树。Nodrec 按用户要求严格限制 Shift+F，不采用该特例。
- `FBAFormatRequest::FindRootNode` 优先选择有执行路径关联的 Event／函数入口；纯数据图选择数据树末端。请求等待节点尺寸有效后才执行，并从待处理列表移除已经整理的节点，避免多选重复排版。
- `FEdGraphFormatter::FormatNode` 依次初始化执行节点池、标记回边、建立同行关系、粗排 X、整理参数、计入参数组边界重排 X、按引脚对齐排 Y，并通过碰撞检查分隔分支。Event 根节点优先作为固定锚点；最终用根节点位移补偿恢复整组位置。BA 还会吸附根节点到网格；Nodrec 保留 Event 原始坐标。
- `FEdGraphParameterFormatter` 管理每个主节点的纯数据参数树和共享归属，提供左侧与 Helixing 布局。Helixing 将参数置于使用节点下方；`DoesHelixingApply` 根据参数分叉数和尺寸决定是否退回左侧布局。
- `FKnotTrackCreator` 另行创建、合并、扩展和对齐 Reroute 轨道；注释边界也参与组边界和间距。缓存还支持基于上次相对位置的快速整理。

BA 是结合蓝图语义与实际几何信息的分阶段启发式排版。Nodrec 独立实现其核心思路，复用自己的连线路由，不移植 UE 对象、尺寸磁盘缓存、注释系统或 Reroute 生成。

## 当前实现

入口为 `apps/desktop/src/graph-layout.ts` 的纯函数 `formatGraph`；`GraphEditor` 提供实例实际端口、节点测量尺寸和引脚中心，一次性提交位置及路径修改。无新增依赖、Rust 接口或存储版本变化。

交互规则以 [UI 规范](ui-guidelines.md#蓝图节点)为准。F 以执行线确定 Event 分支，再将上游参数按最终执行消费者归属分组；跨 Event 共享节点在整理单一分支时固定。无执行消费者的数据／媒体节点可归属其上游执行生产者，没有 Event 归属的图作为独立连通部分。共享数据作为入口时，只遍历共享的非执行节点，不进入各 Event 分支。仅识别画布连线，不沿配置 ID、控件 Event 或工具 ID 建立隐式连接。

- 有执行端口或媒体流端口的节点作为主链，避免将 Capture／Encode／Write 当作参数堆叠。执行输出按实际端口顺序展开；汇合放在前驱之后。
- 完整上游参数树只有一个节点且只有一个使用节点时，参数在使用节点下方左对齐；两个以上参数、参数链或未选中的上游参数退回左侧布局。同一参数只安排一次。左侧参数优先按目标输入引脚的实际高度从上到下排列，不按节点 ID 或存储顺序排列；先放置使用节点，再排列它的上游参数。纯数据消费节点（如 Output Path）同样应用此规则。
- 主链横向间距 100、分支避让间距 60，左侧参数横向间距至少 120、行间距 40；参数较多时横向空间按每通道 12 扩展，Helixing 下方间距仍为 25，单位为画布坐标。采用真实尺寸和引脚中心，按节点及参数组边界避让固定节点。多范围整理预先登记全部固定锚点，避免前一个范围覆盖后一个 Event。
- 仅当主节点有从左侧接入的执行／媒体连线时，左侧参数树的节点顶部至少低于这些输入引脚 25 个画布单位，为接入主线预留水平通道；包括嵌套的 Output Path 及其 Directory／Filename 参数。Capture 仅向右输出媒体时，不以下游输出引脚强制压低其 Region／Display 输入链，仍按实际输入引脚对齐。只在 F／Shift+F 排列范围内应用，不实时移动节点或改写主线。
- Event 坐标始终精确保留。无 Event 时，单选固定所选节点；多选的每个独立连通部分选择原位置最靠上的上游根，再按 X、ID 打破平局。移动结果收敛到 1/64 坐标单位，防止测量舍入让重复整理产生未保存状态。
- 环形编辑中间态只在排版约束中忽略 DFS 回边，保留全部实际连线。未完成测量时延后执行，不猜测尺寸；端口集合变化后主动刷新 React Flow 引脚测量。
- 整理范围内部连线的手动 `data.routePoints` 清除，边界线保留；其他边数据、节点参数、数组顺序和 ID 不变。整理保留视口和选择，不自动保存。Events 与 Functions 共用更新路径。

Subway／Ribbon 的有序扇入按端点几何分配通道：对于左右列对齐、源端与目标端上下顺序一致的连线，上行按目标顺序从左到右分配折线通道，下行反向分配。通道在两列之间居中，并按可用宽度收缩；垂直范围不重叠的线仍复用通道。保留 45° 斜向线段与小圆角，不读取节点边界计算实时绕行，不改写手动路径 Pin。

## 验证与限制

模型测试和 Release WebView 验收见 [测试记录](testing.md#节点自动整理)。首版未增加通用撤销、完整连线避障、注释节点或新建节点时自动整理；保留的边界路径可能绕远，固定节点之间原有重叠不会由整理修复。
